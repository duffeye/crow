Crow is a Bluetooth camera remote and ride-screen extension for **Hammerhead Karoo 3** and compatible **DJI Osmo Action cameras**.

Download **crow-v0.8.0.apk** under Assets. A GitHub account is not required.

## New in this version

- Recognizes Osmo Action 4, Action 5 Pro and Action 6 using the camera's approved protocol handshake.
- Builds Photo/Video mode commands for the detected model instead of always addressing an Action 4.
- Displays the detected model and an experimental label for Action 5 Pro and Action 6.
- Reports unsupported camera IDs explicitly. Original Osmo Action, Action 2 and Action 3 are not supported; neither are Osmo 360, Nano or unknown models.
- Keeps existing camera controls, whole-field ride buttons, battery/storage fields and opt-in GPS forwarding.

**Action 5 Pro and Action 6 support is experimental and has not been tested on hardware.** DJI documents their model IDs and the shared protocol. Crow's model-specific mode payloads extend DJI's Action 4 example; firmware behavior still needs verification. Action 4 controls and the combined Karoo extension were previously tested by the user; GPS/Mimo metadata remains experimental on all models.

## Install and test

Sideload the APK onto Karoo using USB debugging (for example, `adb install -r crow-v0.8.0.apk`). This is a debug-signed test APK. If Android rejects an update due to a different signing key, uninstall the previous app, install this APK, and pair again. Keep your working APK as a fallback.

Open Crow Camera, grant Bluetooth permissions, find the camera and approve pairing on its screen. Enable Crow in Karoo's Extensions settings and add Crow Camera fields to your ride profile. Existing field IDs remain unchanged.

For a new camera model, test pairing, reconnect, start/stop recording, taking a still from Video mode, Photo/Video switching, battery/storage reporting and ride-field controls while stationary. Include the camera model and firmware version when reporting results.

GPS forwarding is off by default and needs precise location permission and a good outdoor fix. Successful Bluetooth writes do not prove GPS was embedded in a video or that DJI Mimo overlays work. Validate a short clip separately before relying on it.

See the [compatibility table and testing instructions](https://github.com/duffeye/crow#camera-compatibility-080). Crow is an independent project, not an official Hammerhead or DJI app.
