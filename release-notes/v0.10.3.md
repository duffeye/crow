Bluetooth transport changes for stalled Osmo Action 5 Pro pairing.

Download **crow-v0.10.3.apk** under Assets; no GitHub account is needed.

- Request a larger Bluetooth ATT MTU before discovering camera services, following the connection order used by DJI's demo.
- Use the negotiated write size rather than always splitting frames into 20-byte fragments. Keep the default size when MTU exchange fails or cannot start.
- Support both Android notification callbacks and copy the received bytes before processing them.
- Count received notifications and decoded protocol frames in the final-approval timeout message, alongside the negotiated payload size. No packet contents, verification codes, GPS coordinates or device identities are logged.
- Update GPS write completion accounting for the negotiated fragment count.

This changes the transport used during pairing, but is not hardware-verified. The reported Action 5 Pro failure occurs before Crow parses final approval. MTU negotiation is a plausible compatibility fix, not a confirmed diagnosis. Action 5 Pro/Action 6 support and GPS overlay timing remain experimental.

Validation: 48 unit tests, debug APK build and Android lint passed locally, including negotiated/default packet sizes and both Android notification callbacks.

Sideload using USB debugging, for example `adb install -r crow-v0.10.3.apk`. This is a debug-signed test APK. If Android rejects an update due to a different signing key, uninstall the previous build, install this APK, and pair/configure Crow again. Keep your working APK as a fallback.
