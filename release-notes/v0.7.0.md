Crow is a Bluetooth camera remote and ride-screen extension for **Hammerhead Karoo 3** and **DJI Osmo Action 4**.

Download **crow-v0.7.0.apk** below. No GitHub account is needed to download release assets. The source-code archives are not installable apps.

Features:
- Start and stop video recording, take still photos, and switch Photo/Video mode.
- Remember the approved camera and reconnect when Crow opens.
- Add separate ride-screen fields for Record, Photo, Status, Mode, Battery, Video left (hours/minutes), and Photos left.
- Tap anywhere inside Record, Photo, and Mode fields to use the control.
- Experimental opt-in GPS forwarding from the device to the camera.

## Install and connect

1. Download the APK and sideload it onto your Karoo, for example with USB debugging and `adb install crow-v0.7.0.apk`.
2. Open **Crow Camera**, grant Bluetooth permissions, find the Action 4 and confirm pairing on the camera.
3. Enable Crow in the Karoo Extensions settings, then add Crow Camera fields to your ride profile.
4. Test the controls while stationary before using them on a ride.

This is a **debug-signed test APK**. If Android rejects an update because the previous APK has a different signing key, uninstall the old app before installing this one; pairing and app settings will need to be restored. Keep a copy of your working APK. A persistent production signing key is not configured yet.

## Experimental GPS

GPS forwarding is off by default. Enable **Forward GPS to camera** in Crow, grant precise Location permission, and wait outdoors for a good fix. The foreground service continues while you use ride screens; stop it using the switch or notification.

Completed Bluetooth writes do not prove the camera saved GPS metadata. Camera firmware compatibility, DJI Mimo dashboards, and timing still need physical-device validation. Crow does not burn overlays into video pixels. Make a short outdoor test clip and check it in DJI Mimo before relying on GPS forwarding.

See the [README](https://github.com/duffeye/crow#readme) for full setup, permissions, limitations, and testing instructions. Crow is an independent project, not an official Hammerhead or DJI app.
