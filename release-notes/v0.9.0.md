Battery-efficiency improvements for Crow Camera on Hammerhead Karoo 3.

Download **crow-v0.9.0.apk** under Assets; a GitHub account is not required.

## Changes

- Request and forward fresh GPS at **1 Hz**, reduced from up to 10 Hz. Faster provider callbacks are rate limited too.
- Automatically release Crow's GPS request and satellite listener when the camera is disconnected, asleep or has stale status. Resume with fresh fixes when an awake camera returns. The GPS switch remains on while forwarding is paused.
- Request a lower-power Bluetooth connection interval after pairing; Android/camera firmware may ignore this request.
- Share one ride-field refresh scheduler and avoid rebuilding or sending unchanged fields. Static previews render once and disconnected fields do not keep a repeating UI timer.
- Pause ride-field refresh work while the screen is off and refresh when it turns on. Camera controls and enabled GPS forwarding keep working independently.
- Filter Bluetooth searches to DJI advertisements, use low-power scanning, and deduplicate search results. Searches still stop after 12 seconds.
- Avoid resetting unchanged text in the foreground app.

DJI fixes camera status pushes at 2 Hz, so that subscription is unchanged. GPS remains off by default. While enabled, it stays active at 1 Hz when a connected camera is awake, including before recording to allow GPS warm-up. Normal Karoo GPS/ride recording is not stopped by Crow. Camera sleep and recording are never changed automatically to save battery.

**Actual battery savings have not been measured.** The changes reduce unnecessary work and maximum GPS packet traffic, but hardware/firmware and other apps determine total power use. A 1 Hz GPS stream may produce less smooth overlays; validate a short moving clip in DJI Mimo. Check controls remain responsive and forwarding pauses/resumes correctly after camera sleep/disconnection.

## Compatibility and installation

Action 4 support is retained. Action 5 Pro and Action 6 support remains experimental and needs hardware validation. Original Osmo Action, Action 2, Action 3, Osmo 360, Nano and unknown models remain unsupported. GPS/Mimo metadata support is experimental on all models.

Sideload the APK using USB debugging (for example, `adb install -r crow-v0.9.0.apk`). This is a debug-signed test build. If an update fails because of a different signing key, uninstall the previous build, install this APK, then pair and configure Crow again. Keep your working APK as a fallback.

See the [README](https://github.com/duffeye/crow#battery-efficiency-090) for setup and comparison testing. Crow is independent of DJI and Hammerhead.
