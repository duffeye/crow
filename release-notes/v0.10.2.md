Pairing diagnostics and connection timeout fixes for Crow Camera.

Download **crow-v0.10.2.apk** under Assets; no GitHub account is needed.

- Stop waiting indefinitely when a camera approves pairing but never sends live status. Crow now disconnects with an explicit error after 15 seconds without the first status packet.
- Allow 45 seconds for camera verification after Bluetooth notification setup, with a separate error when final approval never arrives.
- Report incomplete approval messages, unexpected verification modes, and camera rejection codes instead of silently ignoring them.
- Keep the verification code visible while waiting for final approval.

These changes diagnose stalled pairing; they are not a confirmed fix for the reported Osmo Action 5 Pro connection failure. Physical-device pairing remains unverified. Action 5 Pro/Action 6 support and GPS overlay timing remain experimental. Bluetooth packet sizing is unchanged.

Validation: 46 unit tests, debug APK build, and Android lint passed locally, including regression tests for missing initial status, cancellation of the status deadline, and malformed approval messages.

Sideload using USB debugging, for example `adb install -r crow-v0.10.2.apk`. This is a debug-signed test APK. If Android rejects an update due to a different signing key, uninstall the previous build, install this APK, and pair/configure Crow again. Keep your working APK as a fallback.
