New crow branding for Crow Camera.

Download **crow-v0.10.1.apk** under Assets; no GitHub account is needed.

- Replace the camera app icon with a white crow silhouette on a dark teal background.
- Use the crow for the Karoo extension logo and GPS notification.
- Support adaptive launcher shapes and Android themed icons.

Includes the faster GPS telemetry from 0.10.0. Action 5 Pro/Action 6 support and GPS overlay timing remain experimental.

Sideload using USB debugging, for example `adb install -r crow-v0.10.1.apk`. This is a debug-signed test APK. If Android rejects an update due to a different signing key, uninstall the previous build, install this APK, and pair/configure Crow again. Keep your working APK as a fallback.
